# Interview Kit

A collection of focused interview prep kits for frontend, backend, and HR rounds. Each folder covers one topic with questions, notes, and examples you can use to study or run mock interviews.

## Kits

| Kit | What it covers |
| --- | --- |
| [HTML](html-interview-kit/) | Markup, semantics, forms, accessibility, and browser parsing |
| [CSS](css-interview-kit/) | Layout, specificity, Flexbox, Grid, and responsive design |
| [JavaScript](javascript-interview-kit/) | Language fundamentals, async, DOM, and ES6+ patterns |
| [React](react-interview-kit/) | Components, hooks, state, routing, and rendering |
| [Tailwind CSS](tailwind-interview-kit/) | Utility-first styling, configuration, and responsive classes |
| [Node.js](node-js-interview-kit/) | Runtime, modules, async I/O, and HTTP APIs |
| [MongoDB](mongo-db-interview-kit/) | Documents, queries, indexes, aggregation, and modeling |
| [Git](git-interview-kit/) | Commits, branching, merging, remotes, and collaboration |
| [HR](hr-interview-kit/) | Behavioral questions, STAR answers, and common HR rounds |

## How to use

1. Open the kit that matches the round you are preparing for.
2. Read that folder’s README for the topic map and suggested study order.
3. Practice out loud. Write answers, then compare them with the notes in the kit.
