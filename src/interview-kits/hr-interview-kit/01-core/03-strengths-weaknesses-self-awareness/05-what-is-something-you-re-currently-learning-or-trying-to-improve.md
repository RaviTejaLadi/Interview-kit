# What is something you're currently learning or trying to improve?

### Definition

This question evaluates your **learning mindset**.

For a frontend developer, you could discuss:

- Advanced TypeScript
- React performance
- React Server Components
- Next.js architecture
- Testing
- Accessibility
- Frontend system design
- Web performance
- Browser internals
- Backend fundamentals
- CI/CD

### Sample answer

> “Currently, I'm focusing on improving my understanding of frontend architecture and performance at scale.
>
> I already work with React regularly, so I'm trying to go beyond individual components and understand how larger React applications should be structured.
>
> I'm focusing on areas such as rendering behavior, state management boundaries, code splitting, caching, performance profiling, and maintainable component architecture.
>
> I'm also trying to apply what I learn to real projects rather than just studying the concepts.”

### Better than

> “I'm learning React.”

If you're already an experienced React developer, that sounds too basic.
