# How does this role align with your personal values?

### Definition

This question connects the **job responsibilities with principles that matter to you professionally**.

You don't need to discuss deeply personal beliefs.

For a software engineer, relevant professional values could include:

- Continuous learning
- Ownership
- Quality
- Transparency
- Collaboration
- Customer focus
- Technical excellence
- Simplicity
- Accountability

### Sample answer

> “A few professional values are particularly important to me: continuous learning, ownership, and building quality software.
>
> This role aligns with those values because it involves solving real engineering problems, working collaboratively, and taking responsibility for features rather than simply completing isolated tasks.
>
> I also value continuous improvement. I like environments where engineers can learn from code reviews, technical discussions, production issues, and feedback.
>
> From what I understand about this role, there is a good opportunity to contribute technically while continuing to develop as an engineer.”
