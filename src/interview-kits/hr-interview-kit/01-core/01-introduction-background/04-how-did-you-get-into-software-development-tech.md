# How did you get into software development / tech?

### Definition

This is a **career motivation question**.

The interviewer isn't necessarily looking for a dramatic story. They want to understand:

- What initially interested you
- How you started learning
- What made you choose development
- How you progressed
- Why you continue working in the field

### Sample answer

> “I initially became interested in software development because I enjoyed understanding how websites and applications worked.
>
> I started with the fundamentals of HTML, CSS, and JavaScript. As I became more comfortable with JavaScript, I started exploring React and realized that I enjoyed building interactive applications and solving UI problems.
>
> Over time, I moved from learning individual technologies to understanding how complete frontend applications are structured — things like component architecture, state management, API integration, performance, accessibility, and testing.
>
> That progression is what made me interested in frontend engineering as a career. I enjoy the combination of problem-solving, engineering, and building something that users can directly interact with.”

### Good principle

Keep the answer **authentic**.

You don't need to say:

> “Since childhood, I always wanted to become a software engineer.”

unless that's actually true.
