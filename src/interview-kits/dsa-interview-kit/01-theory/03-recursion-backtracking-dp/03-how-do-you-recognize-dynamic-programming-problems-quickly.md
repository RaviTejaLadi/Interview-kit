# How do you recognize dynamic programming problems quickly?

Dynamic programming (DP) is useful when a problem has:

1. **Overlapping subproblems** (same work repeats)
2. **Optimal substructure** (global optimum built from local optima)

## DP checklist

- Define state: what minimum information represents a subproblem?
- Write recurrence relation.
- Decide top-down (memoization) or bottom-up (tabulation).
- Set base cases.

Common DP interview problems: climbing stairs, coin change, house robber, longest common subsequence.
