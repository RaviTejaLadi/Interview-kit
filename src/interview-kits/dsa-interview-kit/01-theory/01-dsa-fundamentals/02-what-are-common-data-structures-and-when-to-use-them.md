# What are the most common data structures and when should you use each?

## Quick map

- **Array**: fast index access, contiguous storage
- **Linked List**: frequent inserts/deletes when you already have node reference
- **Stack**: last-in-first-out workflows (parsing, backtracking)
- **Queue**: first-in-first-out workflows (BFS, scheduling)
- **Hash Map/Set**: fast lookup, counting, deduplication
- **Heap**: repeated min/max extraction, top-k problems
- **Tree/Trie**: hierarchical and prefix-based search
- **Graph**: relationships/networks

## Interview expectation

You should explain trade-offs, not just definitions. Mention time/space for insert, delete, search, and traversal.
