# 🟢 DSA Interview Questions — Important Only

3. How do you calculate the time complexity of nested loops?
4. What is the difference between an array and a linked list?
5. What is the difference between a `Map`, `Set`, and plain object in JavaScript?

4. What is a prefix sum?
5. What is binary search, and when can you use it?
