# What is Tailwind CSS?

**Tailwind CSS** is a utility-first CSS framework that provides low-level CSS utility classes such as `flex`, `p-4`, `text-center`, `bg-blue-500`, and `rounded-lg`.

Instead of creating a custom CSS class:

```css
/* Define a custom component class */
.card {
  padding: 1rem;
  background: white;
  border-radius: 0.5rem;
}
```

You compose the styles directly:

```html
<!-- Compose styles using Tailwind utilities -->
<div class="p-4 bg-white rounded-lg">
  Card content
</div>
```

### Simple definition

> **Tailwind CSS = a collection of small CSS utilities that you compose to build your UI.**
