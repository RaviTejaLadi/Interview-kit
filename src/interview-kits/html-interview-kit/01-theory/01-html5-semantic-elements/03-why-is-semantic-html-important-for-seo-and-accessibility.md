# Why is Semantic HTML important for SEO and Accessibility?

Semantic HTML is important for both **search engines** and **assistive technologies**.

### SEO

Search engines can better understand the structure and meaning of your content.

For example:

```html
<!-- Semantic structure helps describe the page content -->
<main>
  <article>
    <h1>React Hooks</h1>
    <p>React Hooks allow components to use state and other features.</p>
  </article>
</main>
```

The browser and search engine can understand that this is the **main content** containing an **article** with a heading.

### Accessibility

Screen readers can use semantic landmarks to help users navigate the page.

For example, a screen-reader user can quickly identify:

* Navigation
* Main content
* Articles
* Side content
* Footer

**Important:** Semantic HTML does not automatically guarantee good SEO or accessibility, but it provides a much better foundation.
