# What is Semantic HTML?

**Semantic HTML** means using HTML elements according to their **meaning and purpose**, rather than using generic elements everywhere.

For example:

```html
<!-- Semantic HTML clearly describes the purpose of each area -->
<header>
  <h1>My Website</h1>
</header>

<nav>
  <a href="/home">Home</a>
  <a href="/about">About</a>
</nav>

<main>
  <article>
    <h2>HTML5 Guide</h2>
    <p>Learn about semantic HTML.</p>
  </article>
</main>

<footer>
  <p>© 2026 My Website</p>
</footer>
```

Here, `<header>`, `<nav>`, `<main>`, `<article>`, and `<footer>` communicate the **role** of each part of the page.
