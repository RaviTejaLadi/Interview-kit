| Method      | Purpose                  | Return value           | Stops early? |
| ----------- | ------------------------ | ---------------------- | ------------ |
| `map()`     | Transform elements       | New array              | No           |
| `filter()`  | Select matching elements | New array              | No           |
| `reduce()`  | Accumulate values        | Accumulated result     | No           |
| `forEach()` | Perform an action        | `undefined`            | No           |
| `find()`    | Find first match         | Element or `undefined` | Yes          |
| `some()`    | Check if any match       | Boolean                | Yes          |
| `every()`   | Check if all match       | Boolean                | Yes          |
