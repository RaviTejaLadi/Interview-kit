Here, (n) is the input string length.

| Problem                     | Without built-in methods | With built-in methods |
| --------------------------- | ------------------------ | --------------------- |
| 1. Reverse string           | (O(n))                   | (O(n))                |
| 2. Reverse words            | (O(n^2))                 | (O(n)) average        |
| 3. Palindrome               | (O(n))                   | (O(n))                |
| 4. Anagram                  | (O(n)) average           | (O(n \log n))         |
| 5. Character frequency      | (O(n^2))                 | (O(n)) average        |
| 6. First non-repeating      | (O(n))                   | (O(n^2)) worst case   |
| 7. Remove duplicates        | (O(n^2))                 | (O(n)) average        |
| 8. Longest word             | (O(n))                   | (O(n))                |
| 9. Longest unique substring | (O(n^3))                 | (O(n)) average        |
