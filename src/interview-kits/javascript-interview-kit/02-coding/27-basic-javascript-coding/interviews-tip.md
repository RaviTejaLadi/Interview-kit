# What should you focus on for interviews?

My recommendation is to master the loop-based solutions first. Built-in methods such as `map()`, `filter()`, `reduce()`, `sort()`, and `Set` make code concise, but interviewers often want to understand your algorithmic thinking.

Practice these patterns in this order:

1. Loops and comparisons: reverse a string, find largest/smallest, and sum an array.
2. Two pointers: palindrome checking.
3. Frequency counting: anagrams, character frequency, first non-repeating character, and duplicates.
4. Mathematical logic: factorial, Fibonacci, and prime checking.
5. Complexity analysis: explain why your solution takes \\(O(n)\\) or \\(O(\sqrt n)\\) time.

One important distinction: “without built-in methods” usually means avoiding shortcut methods such as `reverse()`, `sort()`, `reduce()`, and `filter()`, rather than avoiding every built-in property or language feature. In the manual solutions above, properties such as `.length` and basic objects are still used.
