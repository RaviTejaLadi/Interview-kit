# Quick revision table

| No. | Problem              | Core logic                    | Time complexity             |
| --- | -------------------- | ----------------------------- | --------------------------- |
| 1   | Reverse string       | Traverse backward             | (O(n))                      |
| 2   | Palindrome           | Compare both ends             | (O(n))                      |
| 3   | Anagrams             | Character frequency           | (O(n))                      |
| 4   | Largest number       | Track maximum                 | (O(n))                      |
| 5   | Second-largest       | Track two distinct maxima     | (O(n))                      |
| 6   | Smallest number      | Track minimum                 | (O(n))                      |
| 7   | Array sum            | Accumulate total              | (O(n))                      |
| 8   | Character frequency  | Count occurrences             | (O(n)) average              |
| 9   | Count vowels         | Check each character          | (O(n))                      |
| 10  | First non-repeating  | Frequency map and second pass | (O(n)) average              |
| 11  | Duplicate characters | Count and identify repeats    | (O(n)) with a frequency map |
| 12  | Factorial            | Repeated multiplication       | (O(n))                      |
| 13  | Fibonacci            | Maintain previous two values  | (O(n))                      |
| 14  | Prime number         | Check divisors to √n          | (O(\sqrt n))                |

Here, (n) represents the string length, array length, or numeric input, depending on the problem.
