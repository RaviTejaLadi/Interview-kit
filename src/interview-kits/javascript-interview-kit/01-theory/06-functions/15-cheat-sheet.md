# 🧠 JavaScript Functions Cheat Sheet

| Concept                   | Definition                                                                |
| ------------------------- | ------------------------------------------------------------------------- |
| **Function Declaration**  | Named function declared with `function`                                   |
| **Function Expression**   | Function stored in a variable/expression                                  |
| **Arrow Function**        | Concise function syntax with lexical `this`                               |
| **Parameter**             | Variable defined in a function declaration                                |
| **Argument**              | Actual value passed to a function                                         |
| **Default Parameter**     | Fallback value when argument is `undefined`                               |
| **Rest Parameter**        | Collects remaining arguments into an array                                |
| **Callback**              | Function passed to another function                                       |
| **Higher-Order Function** | Function that accepts or returns a function                               |
| **First-Class Function**  | Functions can be treated as values                                        |
| **Pure Function**         | Same input → same output, with no side effects                            |
| **IIFE**                  | Function expression invoked immediately                                   |
| **Recursion**             | Function calling itself                                                   |
| **Composition**           | Combining functions where one output feeds another                        |
| **`call()`**              | Calls function immediately with specified `this`                          |
| **`apply()`**             | Calls function immediately with specified `this` and array-like arguments |
| **`bind()`**              | Returns a new function with specified `this`                              |
